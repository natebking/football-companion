# Score and clock evaluation protocol

Written before running this candidate evaluation. The 2025 NFL outcomes have been examined by earlier research; this is a new fixed-method comparison, not a wholly untouched research dataset. College 2025 has also been used to evaluate the original situation estimator. Prospective live games remain necessary for release claims.

Run NFL and college separately. Keep their original source action labels: recorded pass versus rush, sacks included with passes, scrambles with rushes, no-play penalties/kneels/special teams excluded. This predicts the recorded outcome family, not whether the coach called a dropback. Unknown context and zero-distance rows outside the live situation contract are excluded and counted for both candidate and baseline.

Use the existing score/time context model and team residual, with its fixed two-season half-life. Choose context and identity shrinkage using 2024 weeks 1–9, with the base trained on seasons before 2024. Refit through those early 2024 weeks. Fit one sigmoid calibration on its out-of-sample predictions for the rest of 2024. Fit no parameter on 2025 outcomes. Refit the context/team estimator through all of 2024; evaluate uncalibrated and calibrated forecasts on 2025. Calibration is a two-parameter logistic fit on clipped log-odds, using scikit-learn, fixed C=1000000. A negative slope rejects the candidate.

Compare with the current production estimator trained on its prior three available seasons, on exactly the same plays. Report Brier error, accuracy, 10-bin calibration, game-clustered paired error intervals, and score/clock subgroups. Lower Brier does not by itself demonstrate better calibration. Predeclared research gates: calibrated Brier improvement with paired 95% upper bound below zero; ECE <= .025; absolute calibration-bin error <= .05 for bins with >=500 plays; no score/phase subgroup with >=200 plays worse by >.01 Brier. Failure is reported without retuning to pass.

Export candidate parameters and support counts into ignored research data, not the production probability files. Check Python/JavaScript predictions for all unique held-out inputs. Unknown team uses the league context; unknown required context returns no estimate. Low-support exact contexts remain identified. The model never sees the next result, final charting or raw play text as a feature.

Before any live replacement: reconcile historical/live labels by exact identifiers, verify the application's displayed definition, evaluate saved as-of inputs, and freeze changes before collecting later games. This historical evaluation alone does not prove useful coaching advice, live accuracy, or a coaching-staff effect.

Method reference: [scikit-learn probability calibration](https://scikit-learn.org/stable/modules/calibration.html). The base model and calibration data must be disjoint; reliability curves accompany probability error.

Source audit amendment after the first fixed-method run: 41,650 eligible college records have a structured clock different from the explicit leading clock in the written report; 219 cross a model phase boundary, all in 2025. The final run uses that explicit snap clock when available, using the ingester's shared parser. Keep the original run in ignored data for comparison. Earlier college reports usually lack the explicit clock; their structured clock's exact snap semantics remain unverified. This is a source-input correction, not a new hyperparameter search or a claim of independent clock validation.

Source-label amendment: apply the corrected production CFBD classifier before fitting either estimator. Explicit no-plays are excluded even if the source type says run/pass, and text-resolved scrambles stay with rushes. Preserve the original parquet and count changed flags in the report. These repairs changed 242 source rows and removed 106 2025 test rows; baseline and candidate use identical repaired inputs. No score/time threshold or fitting grid changed in response to test outcomes.
