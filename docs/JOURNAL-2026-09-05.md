# Game journal, post-game review and deeper teaching

September 5, 2026. This release saves the record needed to evaluate the companion while making the default teaching more tactical. Production tendency percentages remain unchanged.

## What is saved

`web/journal.js` stores separate games in this origin's localStorage. It preserves immutable source revisions and release events, exact rendered guidance, rounded probabilities actually printed, internal/baseline rates, source revision identities, and optional observations. Source arrivals are batched into one write. A downloaded journal is self-contained for the captured session, but does not contain the later review dataset; published review files or a new final-source fetch supply that comparison.

The journal records whether a prompt was rendered with the app visible, covered by a panel, or in the background. It cannot establish that a person read the prompt. Imported history on first opening a game is marked separately and cannot masquerade as live viewing. The pre-snap module receives write-only journal functions; reviewing old or completed plays never changes the live queue, displayed scoreboard, or TV delay.

Guidance-to-play links require the exact pre-snap situation. Intermediate transitions clear old links even when a batch of updates ends in the same field position. No matching by repeated game clock. One source report may have many immutable revisions; capture at release binds to the exact report rather than the newest upstream correction.

Limits are 10 games and 2 MB per game, also subject to browser quota. Quota, corrupted storage and count limits produce an explicit pause message; no automatic eviction. Download before removing a journal. Browser data is specific to the hostname and device. Older sessions and records lost before this release are not backfilled as observations.

## The review

The user explicitly opens a review after a spoiler notice. A catalog supplies an enriched Boise State–Oregon review. Other saved games can fetch a final ESPN summary independently of the active live game. Response identity and final status are checked; stale requests cannot replace a different selected review.

CFBD joins are exact game/play/offense joins. The initial Oregon review contains 181 final ESPN reports, 66 matched passing records and 61 matched rushing records. One CFBD passing ID is absent from the ESPN snapshot and is excluded. Only 37 passing yardage decompositions and 56 rushing yard totals pass corroboration. Missing values stay null. Sources and retrieval times remain in the exported review, while raw responses stay under ignored data/.

Review moments are selected for contrasting lessons: yards gained after a catch, distance covered by the throw, and an offensive gain that falls short on third/fourth down. These are reported facts and watching suggestions, not reconstructed routes or claims about a defender's assignment.

Consistency checks compare the exact saved factual explanation with the later report. Newly available fields are enrichment; revised existing facts are changes. Source agreement is not independent proof. Probability/outcome links are retained but no Brier score or prediction-accuracy score is published: the live display/quiz labels and historical NFL/CFB labels differ on sacks, turnovers and some scrambles. A later evaluation must align those source definitions before scoring model probabilities.

## Teaching and research

“Read the game” is the default: 11 lessons about defender choices, motion, leverage, pressure, catch/run yardage and repeated looks. “Start with basics” retains eight introductory lessons. Short wording is an independent preference. The selected game/lesson context is frozen when an observation panel opens; switching games cannot relabel an earlier observation.

The separate coaching experiment covers NFL 2018–2025 and tests later seasons chronologically. See COACHING-PILOT-2026-09-05.md for source-backed role boundaries and full results. The score/time result is promising offline evidence; the caller-transfer result remains inconclusive. No research parameter or probability table changed in this release.

## Validation

Automated checks cover immutable revisions, quota errors, reloading, cross-game identity, arrival/display order, exact displayed probability, prompt transitions, source-enrichment joins, revised player/position facts, teaching levels, and chronology of the coaching experiment. Commands:

```sh
node --test tests/*.test.js
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
node scripts/build-web.mjs
```

Browser checks use the built output: real ESPN polling in Chrome, journal export and persistence across reload, the review spoiler gate, final review rendering, teaching preferences, and phone/dark appearance. A separate headless browser could not reach ESPN reliably; real Chrome verified that boundary, while static review layout was checked headlessly.
