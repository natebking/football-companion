# Match the field to the TV view

The main field diagram now offers **Match TV**, with left/right choices for the current offense. Once selected, **Flip field** reopens those choices. The ball, first-down or goal line, possession arrow, defended-end labels and accessible description all use the same direction. Selection closes the inline controls and returns keyboard focus to the opener. No overlay or fixed bar is added.

The preference is local to the game and league, with team identity checked on read. It persists across reloads and game switches. Regulation possessions preserve each team's end. Quarter changes use the released pre-snap period, so the second/fourth-quarter reversal waits for the configured TV delay. There is no inferred orientation before a viewer selects it. Halftime and each overtime period require another match.

The rule basis is [2026 NFL Rule 4, Section 2](https://static.www.nfl.com/image/upload/fl_attachment/league/tqivdkzt9mu6wdgsh1ku.pdf) and [2026 NCAA Rule 3, Section 1](https://ncaaorg.s3.amazonaws.com/championships/sports/football/rules/PRMFB_RulesBook.pdf). Both specify changes of ends between the first/second and third/fourth quarters and separate choices for the second half. NCAA Rule 3-1-3 gives both possession series in an extra period the same end; the college view retains the selected attacking direction when the offense changes in that period. NFL overtime retains opposite team directions. Camera changes still require a viewer adjustment.

`web/field-view.js` owns orientation and geometry. PRIME supplies only the already-approved situation; it does not inspect raw reports or the current unreleased scoreboard. Football distances, read selection, grades and forecasts are unchanged. A failed preference write leaves the choice usable in memory for the session.

Validation: all 229 JavaScript tests pass. Seven new field tests cover mirrored geometry across every integer field position, goal-to-go, possession changes, quarter changes and reversals, halftime, separate overtime periods, the college overtime exception, reloads, cross-game/league isolation, missing context, malformed storage and failed writes.

An isolated browser fixture used saved Oregon–Boise reports plus explicitly synthetic quarter/possession changes. With a six-second delay, the diagram retained Boise attacking left immediately after receipt, then turned right after the quarter-two update was released. Oregon's subsequent possession moved left with the same defended ends. Reloading restored the first-quarter choice. Desktop light and 390×844 mobile dark views had no horizontal overflow or JavaScript errors. Left/right buttons have 44-pixel height; Escape closes the controls and restores focus. This verifies behavior and layout, not actual stadium-to-TV timing or a detected broadcast direction. Fixture files and screenshots remain in ignored `data/qa/field/`.

Production deployment verification is recorded in the implementation progress document after release.
