# Finished-game replay — September 7, 2026

The replay lets someone evaluate the companion when no game is live. Open it from the home screen or Games, then use Previous/Next or Jump to a moment. Left/right keys step outside dialogs and form controls. The URL retains the current point for reloads or sharing.

## Data boundaries

`web/replay.js` is a pure data adapter. Every selected point becomes a summary with only the available prefix, including original drive IDs. Later scores, clocks, players and future next-play start blocks are excluded. Missing clocks are not filled from a prior report; incomplete scoring updates invalidate stale score totals.

Seeking clears LIVE and PRIME, then calls the same `applySummary` used during a live game. Player counts, drive patterns, last-play takeaways, glossary, historical comparisons and teaching levels therefore use the existing pipeline. The replay does not add a separate analysis model.

Replay is a separate page session. It does not poll ESPN game/scoreboard endpoints, save a game selection, change the saved TV delay, or record journal entries, predictions, exposure counts or simulated diagnostics. Settings deliberately changed by the viewer, such as theme or teaching level, still persist. Exit replay returns to the normal app.
